# Business Model Canvas: Mr. Wright Adventures

This document outlines the business model for Mr. Wright Adventures, a premium concierge and logistics service for travelers in Costa Rica.

| Key Partnerships | Key Activities | Value Propositions | Customer Relationships | Customer Segments |
| :--- | :--- | :--- | :--- | :--- |
| - Local agents (drivers, guides, errand runners)<br>- Hotels and accommodation providers<br>- Supplier partners (helicopter services, tour operators, clinics)<br>- Travel agencies and brokers<br>- Payment gateways (Stripe, PayPal)<br>- Technology partners (messaging, cloud storage) | - Managing bookings and assignments<br>- Coordinating local agents<br>- Baggage handling and tracking<br>- Providing concierge services<br>- Managing partnerships<br>- Platform development and maintenance<br>- Marketing and customer acquisition | - **Certainty & Convenience:** Reliable, seamless travel experiences.<br>- **Trust & Premium Service:** A trusted, high-quality local operator.<br>- **Differentiated Offering:** Integrated concierge, logistics, and medical support with real-time visibility.<br>- **Operational Excellence:** Reliable bookings, baggage tracking, and SLA assurances. | - High-touch, trust-based relationships<br>- Simple and intuitive customer experience (CX)<br>- Automated notifications and updates<br>- 24/7 on-call support and escalation | - **Primary:** International travelers to Costa Rica (including families and post-op clients).<br>- **Secondary:** Corporate clients and travel agencies. |
| **Key Resources** | **Channels** | | | |
| - Network of local agents and partners<br>- Proprietary digital platform (web app, admin dashboard, agent app)<br>- Mr. Wright's local expertise and reputation | - Word-of-mouth referrals<br>- Direct bookings via digital platform (web/mobile)<br>- WhatsApp-based agent interactions<br>- Partnerships with hotels and travel agents<br>- Digital marketing (social media, influencers) | | | |
| **Cost Structure** | **Revenue Streams** | | | |
| - Payments to local agents and suppliers<br>- Technology development and maintenance costs<br>- Marketing and customer acquisition costs<br>- Administrative and support staff salaries<br>- Insurance and regulatory compliance costs | - **Transactional Fees:** Service fees for airport transfers, luggage handling, etc.<br>- **Subscription Revenue:** Premium concierge subscription for perks and priority service.<br>- **Commissions:** Margins on add-on services (helicopter, tours, partner referrals).<br>- **B2B/White-Label:** Packaged services for resale by travel agents and hotels. | | | |
