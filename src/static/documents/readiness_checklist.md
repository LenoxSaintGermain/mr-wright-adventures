> # Mr. Wright Adventures - Pre-Launch Readiness Checklist

**Version:** 1.0  
**Last Updated:** October 2025  
**Owner:** Mr. Wright

---

## 1. Purpose

This checklist provides a comprehensive, actionable list of all items that must be completed before the official launch of Mr. Wright Adventures. It is designed to be a practical tool to ensure that no critical step is missed in the lead-up to going live. Use this checklist to track progress and identify any remaining gaps that need to be addressed.

---

## 2. Readiness Checklist

### **Phase 1: Legal, Financial & Compliance**

| Status | Item | Notes |
|:---:|---|---|
| ☐ | **Business Registration:** Company legally registered in Costa Rica. | Obtain the Cédula Jurídica. |
| ☐ | **Tax ID:** Registered with the Costa Rican tax authorities. | |
| ☐ | **Tourism License (ICT):** Application submitted and acknowledged by the Instituto Costarricense de Turismo. | While not strictly required for this business model, it adds significant credibility. |
| ☐ | **Bank Accounts:** Business checking and USD domiciliary accounts opened. | Essential for managing local expenses and international revenue. |
| ☐ | **Payment Gateway:** Stripe account fully verified and linked to the business bank account. | Test transactions should be completed. |
| ☐ | **General Liability Insurance:** Policy active with a minimum of $2,000,000 coverage. | Certificate of Insurance should be on file. |
| ☐ | **Website Legal Documents:** Terms of Service and Privacy Policy drafted by a legal professional and published on the website. | Must be compliant with data protection laws (e.g., GDPR). |

### **Phase 2: Technology & Systems**

| Status | Item | Notes |
|:---:|---|---|
| ☐ | **Website & Booking Platform:** Live, tested, and fully functional on the permanent domain. | Includes frontend and backend. |
| ☐ | **WhatsApp Business API:** Activated, with approved message templates for automated notifications. | |
| ☐ | **CRM System (HubSpot):** Fully configured with custom fields for bookings and partner data. | |
| ☐ | **Flight Tracking API (FlightAware):** Integrated and tested to ensure real-time flight data is being received. | |
| ☐ | **GPS Tracking System (Trakm8):** Deployed in all primary vehicles and visible on the coordinator dashboard. | |
| ☐ | **Google Workspace:** All team members have active accounts (`@mrwrightadventures.com`), and shared calendars are set up. | |
| ☐ | **Notion Knowledge Base:** All SOPs, training materials, and contact lists are populated and accessible to the team. | |

### **Phase 3: Team & Training**

| Status | Item | Notes |
|:---:|---|---|
| ☐ | **Core Team Hired:** Operations Manager and Customer Success Lead are hired and onboarded. | |
| ☐ | **Field Agents Recruited:** Agents for SJO and LIR regions are contracted and trained. | These are the priority regions for launch. |
| ☐ | **Driver Pool Vetted:** A minimum of 5 backup drivers per priority region are vetted (background checks, vehicle inspections) and have signed agreements. | |
| ☐ | **Medical Liaison:** A qualified Medical Liaison is contracted and trained on medical tourism protocols. | |
| ☐ | **Team Training Completed:** All team members have completed training on the technology stack, communication protocols, and all service workflows. | Conduct role-playing exercises for key scenarios. |
| ☐ | **On-Call Roster:** A 24/7 on-call rotation for emergencies is created and published. | |

### **Phase 4: Partnerships & Network**

| Status | Item | Notes |
|:---:|---|---|
| ☐ | **Tier 1 Hotel Partners:** A minimum of 3 strategic hotel partnerships are signed. | e.g., Four Seasons, Andaz. |
| ☐ | **Vacation Rental Partners:** A minimum of 2 major vacation rental management companies are signed. | |
| ☐ | **Ground Transport Partners:** Primary and backup transportation providers for SJO and LIR are contracted and integrated. | |
| ☐ | **Helicopter Partner:** At least one helicopter charter company is contracted. | |
| ☐ | **Activity & Tour Providers:** A curated list of at least 10 top-rated tour providers are onboarded. | |
| ☐ | **Medical Facility Partners:** Agreements are in place with at least one JCI-accredited hospital and one reputable dental clinic. | |
| ☐ | **Restaurant Network:** Relationships established with at least 15 key restaurants for priority reservations. | |

### **Phase 5: Marketing & Launch**

| Status | Item | Notes |
|:---:|---|---|
| ☐ | **Website SEO:** Basic on-page SEO is completed for all service pages. | |
| ☐ | **Social Media Profiles:** Instagram and Facebook profiles are created, branded, and populated with initial content. | |
| ☐ | **Launch Marketing Materials:** Co-marketing materials for partners are ready. | |
| ☐ | **Email Sequences:** All automated email campaigns (post-booking, post-trip, re-engagement) are configured and tested. | |
| ☐ | **Soft Launch:** A beta test with a small group of "friends and family" is successfully completed to iron out any final issues. | |
| ☐ | **Public Launch Plan:** A date is set for the public launch, and an announcement plan is in place. | |
