## 1. How to Use This Template

This Gap Analysis template is a living document designed to be used in conjunction with the **Pre-Launch Readiness Checklist**. Its purpose is to systematically identify and address any gaps between our desired state (fully ready for launch) and our current reality. 

**Process:**
1.  Review the **Pre-Launch Readiness Checklist** weekly.
2.  For any item marked as incomplete (☐), create a corresponding entry in the table below.
3.  Work with the assigned owner to develop a clear action plan and set a realistic deadline.
4.  Update the status of each gap weekly until it is resolved and the corresponding item on the readiness checklist can be marked as complete (☑).

### Priority Levels
-   **High:** Must be resolved before launch. A showstopper.
-   **Medium:** Should be resolved before launch, but workarounds exist.
-   **Low:** Can be resolved post-launch without significant impact.

### Status Levels
-   **Not Started:** No action has been taken yet.
-   **In Progress:** An owner is actively working on the action plan.
-   **Blocked:** Progress is stalled due to an external dependency.
-   **Completed:** The gap has been resolved.
