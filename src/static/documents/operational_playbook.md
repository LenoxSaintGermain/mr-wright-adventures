# Mr. Wright Adventures: Operational Playbook

## 1. Introduction

This playbook outlines the standard operating procedures (SOPs) for delivering Mr. Wright Adventures' core services. It is designed for administrators and local agents to ensure consistent, high-quality service delivery.

## 2. Core Services & Workflows

### 2.1. Airport Pickup & Luggage Management

**Objective:** To provide a seamless and secure airport arrival experience, including baggage handling and transport to the traveler's destination.

| Role | Actions |
| :--- | :--- |
| **Traveler** | - Pre-books service, providing flight details and accommodation information.<br>- Pre-authorizes baggage handling.<br>- Receives confirmation and real-time updates (agent assigned, baggage collected, ETA). |
| **Admin** | - Receives and confirms booking.<br>- Assigns a local agent based on arrival time and location.<br>- Monitors the process and serves as an escalation point. |
| **Local Agent** | - Accepts the job via the agent app/WhatsApp.<br>- Greets the traveler at the airport.<br>- Collects luggage, applies a unique QR code tag, and scans it to start the chain of custody.<br>- Updates status in-app (e.g., "Baggage Collected," "En Route").<br>- Transports traveler and/or luggage to the destination.<br>- Scans the tag again upon delivery to the hotel/residence to complete the chain of custody. |

### 2.2. Multi-Tier Transport

**Objective:** To offer a range of transportation options (Economy, Comfort, VIP, Helicopter) with corresponding service levels.

| Role | Actions |
| :--- | :--- |
| **Traveler** | - Selects transport tier during booking.<br>- Receives details of the vehicle and driver/pilot. |
| **Admin** | - Manages vehicle and driver/pilot roster.<br>- Assigns appropriate vehicle/driver based on booking tier.<br>- Coordinates with helicopter partners for VIP bookings. |
| **Local Agent/Pilot**| - Conducts pre-trip vehicle/aircraft check.<br>- Adheres to the specific service standards for the tier (e.g., refreshments for VIP).<br>- Follows designated routes and safety protocols. |

### 2.3. On-Demand Concierge

**Objective:** To fulfill on-demand requests such as grocery shopping, pharmacy pickups, and other errands.

| Role | Actions |
| :--- | :--- |
| **Traveler** | - Submits a request via the platform or a dedicated channel.<br>- Receives confirmation, agent details, and ETA. |
| **Admin** | - Triages and assigns the request to the nearest available agent.<br>- Provides the agent with the necessary details (shopping list, address, etc.). |
| **Local Agent** | - Accepts the concierge job.<br>- Communicates with the traveler if clarification is needed.<br>- Purchases items and provides proof of purchase (e.g., receipt photo).<br>- Delivers items to the traveler and confirms delivery in-app. |

## 3. General Operations

### 3.1. Agent Onboarding

1.  **Application:** Prospective agents apply through a dedicated portal.
2.  **Vetting:** Admin team conducts background checks, verifies references, and assesses suitability.
3.  **Training:** New agents complete training on SOPs, platform usage, and customer service standards.
4.  **Activation:** Once training is complete, the agent's profile is activated, and they can start accepting jobs.

### 3.2. Service Level Agreements (SLAs) & Escalation

- **On-Time Pickup:** Agents must be at the pickup location at the scheduled time.
- **Baggage Handling:** Baggage must be delivered to the correct destination within the promised timeframe, with no damage.
- **Communication:** All parties must receive timely and accurate updates.

**Escalation Path:**

1.  **Immediate Issue:** Traveler or agent contacts the admin via a dedicated support channel.
2.  **Admin Triage:** Admin assesses the situation and attempts to resolve it (e.g., assigning a backup agent).
3.  **Senior Management:** If the issue cannot be resolved by the admin, it is escalated to Mr. Wright or a lead agent for a final decision.
